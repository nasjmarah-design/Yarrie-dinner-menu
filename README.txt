YARRIE DINNER OFFLINE PWA

Upload index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, apple-touch-icon.png to the same GitHub Pages directory.

IMPORTANT: theme.jpg must already exist in that SAME directory; it is not included in this ZIP because it was not supplied. Do not delete it. The service worker requires it for complete offline PDF printing.

Deploy while online. Open the live site in normal Safari, wait until the app shows Offline files ready, then Share > Add to Home Screen. Open the new Home Screen icon once online. Switch to Airplane Mode and test Fill sample menu, manual weekday, save/load, PDF generation, and printing.

Do not use SingleFile for this version. Existing saved menus in Safari may not be shared with the standalone Home Screen app.

Do not delete site data or uninstall the app before exporting needed saved menus.
